# Video Downloader

Flutter Android project using `yt-dlp-android` for metadata extraction and downloads.

## Requirements

- Flutter 3.38.x or newer
- Android SDK
- Android 7.0 / API 24 or newer

## Run

```powershell
flutter pub get
flutter run
```

The app is intended for downloading content which you are authorized to download and should be used in accordance with the applicable platform terms and copyright law.
